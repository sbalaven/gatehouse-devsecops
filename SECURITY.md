# Security policy

Gatehouse is an educational portfolio lab, not a production service. Do not store sensitive information in it.

For a suspected vulnerability, use GitHub's private vulnerability reporting if the repository owner enables it. Do not publish working credentials, personal data, or sensitive deployment details in an issue. For a confirmed leaked credential, revoke or rotate it before rewriting history or addressing the scanner finding.

See `docs/THREAT-MODEL.md` for the controls and explicitly unimplemented protections. Automated scanner results are evidence to review, not a security certification.
